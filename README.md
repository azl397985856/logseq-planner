# Logseq 计划助手

两种使用方式：

## 🌐 在线版（推荐日常使用）

**https://lucifer.ren/logseq-planner/**（或 https://azl397985856.github.io/logseq-planner/）

纯浏览器本地运行，**数据不上传到任何服务器**：

1. 打开网站，点「选择数据目录」，选中你的 Logseq 库目录（含 `pages/` 的那个文件夹）——改动直接写回你本地的 md 文件，目录会被记住，下次一键恢复（需 Chrome/Edge）
2. 没有支持的浏览器也可以点「上传 pages 文件夹」——数据保存在浏览器里（刷新不丢、可编辑），用侧边栏「导出全部 md」取回

## 💻 本地服务版（调试用）

`node server.js` 或双击 `启动.command` → http://127.0.0.1:5217 ，默认读 `~/Documents/logseq`，也可 `node server.js /path/to/graph` 指定。带文件监听实时同步和 Logseq 深链。

## 功能

### 1. 生成新月计划（核心，基于模板）

点右上角 **「✚ 生成新月计划」**，按 `pages/月计划模板.md` 新建：

- **模板可以直接编辑**（网页里改，或 Logseq 里改都行），以后新建的月计划永远用最新模板
- **携带未完成事项**（可选）：选一个月份，它里面 NOW/LATER/TODO/DOING 的条目（连同 LOGBOOK 历史）会按分区插入新计划对应位置；模板里没有的分区会整段追加；也可选「不携带」
- DONE / CANCELED 自动跳过（旧文件里仍有记录）
- 点「预览」先看会携带什么、跳过什么，再点「生成」
- 目标月份已存在时需勾选确认覆盖，旧文件自动备份到 `logseq/logseq/bak/pages/`

### 2. 直接编辑（写回 md）

- **改状态**：点任务的状态标签（NOW/TODO/…）切换
- **编辑**：悬浮任意条目 → ✎，Enter 保存
- **新增**：每个分区末尾「＋ 添加」，可选状态
- **删除**：悬浮 → ✕（有确认）
- **高优先级**：`[#A]` 的任务有红色边条和 ❗A 标记，和普通任务一眼区分

### 3. 实时同步 + 链接跳转

- 服务监听 `pages/` 目录：在 Logseq 里改，网页自动刷新；网页里改，Logseq 实时同步。唯一数据源是 markdown
- `[[页面]]` 链接可以直接点击跳转；页面不存在会自动创建（和 logseq 行为一致）

## 目录结构

- `月计划模板.md` —— 新月计划的骨架，随便改（自媒体/工作/Bonus 在模板里只是空分区，具体内容在各月份文件里）
- `工作.md`、`Bonus.md` —— 从月度计划移出的内容（计划里留了 `[[工作]]`/`[[Bonus]]` 链接）
- `migrate-2026-10.js` —— 一次性迁移脚本（已完成，留着备查）

## 安全性

- 只读写 `pages/` 下的 markdown，只监听 127.0.0.1
- 覆盖已有月计划前自动备份；普通编辑改错了再改回去即可
